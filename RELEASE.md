## The font

- Family "PUDDY Odysseus"; styles Regular (400), Medium (500), Bold (700), Black (900); version 1.100.
- 88 glyphs in every weight: .notdef and space (no-break space maps to it), the capitals A to Z, the lowercase a to z, the lining figures 0 to 9, and . , : ; - ' " ( ) ! ? & @ # $ % / + = with the four curly quotes, and the alchemical sign Caput Mortuum 🝎 (U+1F74E), a typographic glyph.
- A kern feature in every weight, measured from that weight's outlines by rule.
- The variable font `fonts/PUDDYOdysseus[wght].ttf`: one axis, wght, 400 to 900, default 400, with the named instances Regular, Medium, Bold, Black.
- Units per em 1000, cap height 700, x-height 450, ascender 790; one line box for hhea, OS/2 typo and OS/2 win, ascender 940, descender -260, line gap 0 (line height 1200), USE_TYPO_METRICS set.
- Designer PUDDY✵CUBE; manufacturer PUDDY Inc.; vendor URL https://puddystudios.com; OS/2 vendor ID "NONE" (no vendor ID is registered).
- Every outline is computed from the square, the circle and the triangle; the changes, version by version, are in FONTLOG.txt.
